В работе выполнено:

Загрузка и предварительная обработка данных: Исходный датасет BMW Cars Market Dataset был загружен. На этапе предварительной обработки были удалены незначимые признаки (car_id, color, service_history, country_sold), а также столбцы, которые имели низкую корреляцию с целевой переменной price_usd (engine_size, drivetrain, fuel_consumption_l_per_100km, co2_emissions_g_km). Категориальные признаки были оцифрованы, а пропущенные значения заполнены медианой.
Выявление и удаление выбросов: С помощью метода межквартильного размаха (IQR) были выявлены и удалены выбросы в ключевых числовых признаках: price_usd, mileage_km и horsepower. Это позволило улучшить качество данных для дальнейшего анализа и моделирования.
Разведочный анализ данных (EDA): Были построены диаграммы размаха для анализа распределения ключевых числовых переменных до и после удаления выбросов. Также были построены гистограммы для визуализации распределения цен по моделям автомобилей, что позволило получить представление о ценовых сегментах различных моделей.
Разделение данных: Данные были разделены на обучающую (80%) и тестовую (20%) выборки для корректной оценки производительности моделей.
Обучение и оценка моделей регрессии: Были обучены пять различных моделей регрессии: Linear Regression, Ridge Regression, Decision Tree Regressor, Random Forest Regressor и Gradient Boosting Regressor. Производительность каждой модели оценивалась с использованием метрик R², RMSE и MAE.
Основные выводы:

Сравнение моделей:
Random Forest Regressor показал наилучшие результаты среди всех моделей, достигнув самого высокого значения R² (0.9606) и самых низких значений RMSE (4602.52) и MAE (3428.98). Это свидетельствует о его высокой способности предсказывать цены автомобилей с хорошей точностью.
Gradient Boosting Regressor также продемонстрировал очень хорошие результаты, уступая Random Forest Regressor лишь незначительно.
Decision Tree Regressor показал средние результаты, а Linear Regression и Ridge Regression оказались наименее точными, что указывает на нелинейный характер зависимости цены от признаков.
Визуализация производительности: Графики сравнения метрик и графики "Актуальные vs. Предсказанные цены" для каждой модели наглядно подтвердили превосходство ансамблевых методов (Random Forest, Gradient Boosting) над более простыми моделями.
Заключение:

Наилучшей моделью для предсказания цены автомобиля в данном наборе данных является Random Forest Regressor. Его высокая производительность указывает на сложность взаимосвязей между признаками и ценой, которую ансамблевые методы способны эффективно улавливать. Для дальнейшего улучшения точности модели можно рассмотреть дополнительную настройку гиперпараметров (hyperparameter tuning) для Random Forest Regressor или Gradient Boosting Regressor.
