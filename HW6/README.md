##  Отчет по Анализу Поведения Пользователей Netflix

Этот отчет представляет собой подробный анализ поведения пользователей платформы Netflix, включая Исследовательский Анализ Данных (EDA), кластеризацию пользователей с использованием различных алгоритмов и обнаружение аномалий, связанных с предсказанием пола.

### 1. Обзор Датасета и Предварительная Обработка

Исходный датасет содержит информацию о `50,000` пользователях Netflix и включает `20` различных признаков, таких как возраст, пол, страна, тип подписки, ежемесячная плата, история просмотров и другие. Для целей анализа была создана уменьшенная версия датасета (`df_lite`), содержащая `10,000` случайных записей.

**Ключевые шаги предобработки:**
*   **Загрузка данных:** 
*   **Создание уменьшенной версии:** Для ускорения и упрощения вычислений была создана `df_lite` (10,000 строк).
*   **Обработка пропущенных значений:** Пропущенные значения не обнаружены.
*   **Кодирование категориальных признаков:** Категориальные признаки (`country`, `subscription_type`, `payment_method`, `primary_device`, `favorite_genre`, `churned`) были закодированы с использованием `LabelEncoder`.
*   **Масштабирование признаков:** Все признаки были стандартизированы с использованием `StandardScaler` для обеспечения сопоставимости масштабов.
*   **Сохранение целевой переменной:** Колонка `gender` была сохранена как `true_labels` для последующей оценки качества кластеризации и анализа аномалий.

### 2. Исследовательский Анализ Данных (EDA)

EDA был проведен для понимания структуры и характеристик данных.

**Основные выводы EDA:**
*   **Распределение числовых признаков:** Визуализации (гистограммы с KDE) показали разнообразные распределения для числовых признаков, некоторые из которых имеют нормальное или близкое к нему распределение, другие – скошенные.
*   **Распределение категориальных признаков:** Столбчатые диаграммы позволили оценить частоту встречаемости различных категорий. Например, `gender` распределен почти равномерно между Male, Female и Other (~33% каждая), а `country` показывает относительно равномерное распределение по представленным странам.
*   **Половозрастная структура:** Детальный анализ пола и возраста показал сбалансированное распределение полов и типичное возрастное распределение пользователей.
*   **Матрица корреляций:** Тепловая карта корреляций числовых признаков выявила следующие сильные или умеренные корреляции:
    *   `watch_sessions_per_week` и `binge_watch_sessions`: `0.994` (очень сильная положительная) - ожидаемо, так как больше сессий часто означает больше запойных просмотров.
    *   `content_interactions` и `recommendation_click_rate`: `0.892` (очень сильная положительная) - активные пользователи чаще кликают на рекомендации.
    *   Другие корреляции были в основном слабыми.

### 3. Определение Оптимального Количества Кластеров (K)

Для определения оптимального `K` были использованы следующие методы:
*   **Метод локтя (Elbow Method):** Указал на `K = 3`.
*   **Коэффициент силуэта (Silhouette Score):** Максимальное значение силуэта (`0.085`) было достигнуто при `K = 2`. Однако, это значение очень низкое, что говорит о слабой разделимости кластеров.
*   **Метод Болдуина (Baldwin's Method):** Указал на `K = 5`.
*   **Gap-статистика:** Показала `K = 4`.

**Консенсусное K:** На основе голосования методов, **оптимальным количеством кластеров было выбрано `K = 3`**.
